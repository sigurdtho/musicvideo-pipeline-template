# Fit check — __SLUG__

Status: **not run**. Low weight. A fit check, not a popularity score, and not a gate. It does not block a stage.

Run it once when the concept and the lyric draft both exist. Run it again before the style guide is approved. Put the latest run in `qc/coherence.json` so the decision page can show it. The card has no choice buttons, and it does not sit under "Waiting for you".

Score each pair from 1 to 5.

| Score | Meaning |
| --- | --- |
| 1 | The two fight. |
| 2 | They strain. |
| 3 | Workable once the note is dealt with. |
| 4 | They fit. |
| 5 | They are locked. |

The pairs are concept ↔ lyrics, lyrics ↔ genre/tempo, genre ↔ visual style, mood consistency, and audience fit.

Each score needs a reason, and a comparable work that already succeeded at that kind of pairing. Name the device worth copying. The size of that work's audience is not the score.

## Checklist

- [ ] The lyric says the concept's arc.
- [ ] Verse words per second sit at or under about 2.3 for a slow genre, on the page and on the take in front.
- [ ] The pictures can carry the tempo, with the cut rules, without a second grade.
- [ ] The mood does not flip between sections unless the brief says why.
- [ ] The audience is named. Each comparison names a device.
